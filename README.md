# TAPZEN SaaS

TAPZEN source archive is stored in this repository as `TAPZEN_MVP_COMPLETE_AI.zip`.

This repository currently contains the source archive, not an extracted deployable Vercel workspace. Extract the archive and configure the correct Vercel Root Directory before deployment. The API requires PostgreSQL and server-only environment variables. Do not commit secrets.

See the archive's README and docs for setup and known verification limitations. The archive has not been independently built or deployed in this repository yet.
